# 위원회 통합 운영관리 · DEMO

개별 위원회 운영관리와 전체 위원회 총괄 조회를 한 화면에서 처리하는 도구입니다.
기존에 나뉘어 있던 `03-committee-manager`(개별 관리)와 `04-committee-dashboard`(총괄 대시보드)를 합쳤습니다.

## 화면 구성

**총괄 화면** — 홈 / 위원회 현황 / 위원 구성 / 회의 / 청년 / 예산 / 점검센터 / 데이터

위원회 목록에서 이름을 누르면 **개별 위원회 화면**으로 들어갑니다.
위원 명부, 회의 기록, 회의록, 집행내역을 위원회 단위로 관리합니다.

## 점검 신호

여섯 가지를 자동으로 확인해 총괄 화면에 띄웁니다.

- 성별 구성 — 위촉직 특정 성별 편중
- 청년 위원 비율
- 연간 회의 개최 실적
- 회의록 공개 여부
- 장기 미개최
- 예산 집행

## 데이터에 관하여

> **이 페이지의 모든 데이터는 기능 시연을 위해 만들어낸 가상 데이터입니다.**
> 위원회·위원·회의·예산·점검 결과는 실재하는 기관이나 위원회와 무관하며,
> 위원명은 전부 `김○○` 형태로 가명 처리했습니다.
> 소속 국·과는 `OO도 / 경제산업국 / 일자리정책과`처럼 일반 명칭을 씁니다.

편집한 내용은 브라우저에만 저장되고 저장소에는 올라가지 않습니다.

## 남은 과제

실제 운영에서는 **개별 위원회 담당자와 총괄 담당자가 서로 다른 사람**입니다.
지금 구조는 한 사람이 전부 보는 것을 전제하므로,
담당자별 소유 범위와 총괄 집계 방식을 설계해 반영해야 합니다.
