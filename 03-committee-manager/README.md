# 경기도 위원회 관리

개별 위원회 운영관리와 전체 위원회 총괄 조회를 한 화면에서 처리하는 도구입니다.
기존에 나뉘어 있던 `03-committee-manager`(개별 관리)와 `04-committee-dashboard`(총괄 대시보드)를 합쳤습니다.
어느 기관이든 쓸 수 있도록 **빈 상태로 시작**할 수 있습니다.

## 시작 화면 · 접속 역할

시작 화면에서 누구로 접속할지 고릅니다.

| 역할 | 보이는 것 |
|---|---|
| 총괄 담당자 | 전체 위원회, 총괄 메뉴(홈·위원회 현황·위원 구성·회의·점검기준·데이터), 모든 개별 위원회 |
| 개별 위원회 담당자 | 고른 위원회만. 총괄 화면·다른 위원회·통합검색 결과가 보이지 않고, 담당자 칸은 바꿀 수 없음 |

데모에서는 두 역할이 같은 브라우저 데이터를 봅니다. 개별 담당자로 입력한 내용이 총괄 화면에 바로 반영되는 것을 확인할 수 있습니다.
왼쪽 위 `경기도 위원회 관리` 제목이나 오른쪽 아래 `시작화면`을 누르면 접속 선택 화면으로 돌아갑니다.
개별 위원회 담당자는 위원회 이름을 몇 글자 입력해 목록에서 고릅니다(방향키·Enter 가능).

> **보안 장치가 아닙니다.** 화면을 나눠 보여줄 뿐이라, 브라우저 데이터에는 모든 위원회가 들어 있습니다.
> 실제로 "자기 것만 보이게" 하려면 서버에서 로그인한 사람의 담당 위원회 데이터만 내려주어야 합니다.

`var DEMO_ONLY=true;`를 `false`로 바꾸면 빈 상태 시작·파일 불러오기 선택지가 다시 나옵니다.

### 전체 선택지 (DEMO_ONLY=false)

페이지를 처음 열면 진입 화면이 뜹니다.

| 선택 | 무엇을 하나 |
|---|---|
| **이어서 작업하기** | 전에 작업하던 위원회 데이터를 그대로 이어서 봅니다 (빈 상태·불러오기로 작업한 적이 있을 때만 보입니다) |
| **데모 둘러보기** | 가상 위원회 20개가 채워진 상태로 기능을 살펴봅니다 |
| **빈 상태로 시작** | 기관명만 넣고 위원회를 하나씩 직접 등록합니다 |
| **저장한 파일 불러오기** | 전에 백업한 JSON을 열어 이어서 작업합니다 |

**페이지를 열 때마다 이 화면이 먼저 나옵니다.** 여러 사람이 둘러보는 공개 페이지라 그렇게 두었습니다.
작업하던 내용은 지워지지 않고 `이어서 작업하기`로 돌아갈 수 있습니다.

### 빈 상태에서

`위원회 현황` 화면의 **+ 위원회 추가** 버튼으로 첫 위원회를 등록합니다.
위원회명만 넣으면 바로 만들어지고, 소관 실·국, 설치근거, 담당자 등은 나중에 채워도 됩니다.
등록 후 개별 위원회 화면으로 들어가 위원과 회의를 추가합니다.

입력한 내용은 **이 브라우저에만** 저장됩니다.
`데이터 관리 → JSON 백업`으로 파일에 보관하세요.

## 화면 구성

**총괄 화면** — 홈 / 위원회 현황 / 위원 구성 / 회의 / 점검기준 / 데이터

위원회 목록에서 이름을 누르면 **개별 위원회 화면**으로 들어갑니다.
위원 명부, 회의 기록(회의록 공개·누리집 게시 포함), 집행내역을 위원회 단위로 관리합니다.

각 목록의 **CSV 내보내기**는 화면에 보이는 표를 검색·필터 결과 그대로 내려받습니다.

## 기준일

`데이터 → 기준일`에서 날짜를 고르면 임기 D-Day, 청년 나이(만 19~39세), 올해 회의 수, 점검 신호를 그 날짜 기준으로 계산합니다.
분기 실적을 낼 때는 서식의 기준일(예: 6월 30일)로 맞추면 됩니다. 고르지 않으면 오늘 날짜를 씁니다.

## 점검 신호

아홉 가지를 자동으로 확인해 총괄 화면에 띄웁니다. 위반 판정이 아니라 먼저 확인할 후보입니다.

| 신호 | 확인하는 것 |
|---|---|
| 성별 | 위촉직 중 한 성별이 60% 초과 |
| 청년 | 위촉직 중 청년(만 19~39세) 20% 미만 (청년정책 위원회는 30%) |
| 회의 | 상설위원회인데 올해 회의 2회 미만 |
| 회의록 | 비공개 회의록인데 비공개 사유가 없음 |
| 회의록기한 | 회의 종료 후 30일이 지났는데 홈페이지 게시일이 없거나 늦음 |
| 장기미개최 | 상설위원회인데 1년 넘게 회의 없음 |
| 예산 | 올해 예산이 있는데 집행액 0원 |
| 겸직 | 같은 위촉직 위원(이름+생년월일)이 위원회 3개 초과 |
| 연임 | 위촉직 위원 연임 횟수 3회 초과 |

예산 집행액은 따로 입력하지 않고 회의별 집행내역(참석수당·심사수당·속기비·기타)을 합쳐 계산합니다.

## 설치근거 조문 바로가기

위원회 기본정보의 `설치근거(법령)`, `설치근거(조례)`에 적은 내용을 읽어 국가법령정보센터(law.go.kr) 조문 링크를 만듭니다.
`소프트웨어 진흥법 제50조`, `경기도 지능정보화 조례 제12조, 제13조`, `지방재정법 제37조의2`처럼 서식에 적는 방식 그대로 인식합니다.
개별 위원회 대시보드와 위원회 현황 목록에 표시됩니다.

- 법령은 해당 조문으로 바로 열리고, 조례·규칙은 조례 전문 화면으로 열립니다. 법제처 한글주소가 자치법규의 조문 단위 주소를 지원하지 않기 때문입니다.
- 법령·조례 이름이 law.go.kr에 등록된 이름과 정확히 같아야 열립니다.
- 조례는 국가법령정보센터가 조문 단위 주소를 제공하지 않아 조례 전체 화면이 열립니다.
- 조문 본문을 도구 안에 직접 띄우려면 법제처 Open API 키와 서버가 필요합니다. 지금은 `근거 조문 내용` 칸에 붙여 두면 대시보드에 함께 보입니다.

## 회의록 누리집 게시

회의록은 경기도 누리집 [위원회 회의록 게시판](https://www.gg.go.kr/bbs/board.do?bsIdx=495&menuId=1840)에 회의 후 30일 이내 올립니다.
별도 메뉴 없이 `회의 관리`에서 함께 관리합니다.

- 회의 목록의 `회의록 · 누리집 게시` 칸에 공개 여부와 게시 상태가 보입니다. 게시글 주소를 넣어 두면 `바로가기` 버튼이 생기고, 아직 안 올렸으면 기한 D-day가 보입니다.
- 회의 `수정` 창 아래쪽에서 공개 여부·비공개 사유·게시일·게시글 주소를 입력하고, `저장하고 게시 문구 만들기`로 게시판 형식의 제목(`2026년 제1차 경기도 ○○위원회 회의록`)과 본문을 복사합니다.
- `누리집에서 이 위원회 회의록 찾기`: 게시판을 열고 위원회 이름을 복사해 둡니다. 게시판 검색창에 붙여넣으면 됩니다. 게시판의 검색 주소 형식을 확인하면 `GG_BOARD_SEARCH`에 넣어 바로 검색되게 바꿀 수 있습니다.

## 예산과목

집행내역 화면에서 연도를 고르고 `예산과목 입력`으로 과목별 예산액을 넣습니다. 과목 합계가 그해 예산액입니다.
회의별 집행을 수정할 때 예산과목을 고르면 과목별 집행액·잔액·집행률이 계산됩니다.

## 운영실적 서식 엑셀

`데이터 → 기준일 · 운영실적 서식`에서 **운영실적 서식 엑셀 받기**를 누르면 서식의 1~6번 시트를 채운 엑셀 파일이 내려받아집니다.
개별 위원회 화면의 `설정 → 이 위원회 운영실적 서식`은 그 위원회만 담습니다.

| 시트 | 채우는 방법 |
|---|---|
| 1. 위원회 기본현황 | 위원회 기본정보 그대로 |
| 2. 위원회별 위원 현황 | 기준일에 재임 중인 위원을 세어 자동 계산 |
| 3. 위원 명단 | 기준일에 재임 중인 위원 |
| 4. 개최실적(총괄) | 회의를 연도별로 세어 자동 계산 (최근 7년) |
| 5. 개최실적(세부) | 회의 건별 (최근 5년) |
| 6. 예산현황 | 예산액 입력값 + 회의별 집행내역 합계 (최근 7년) |

- 계·소계·합계 칸은 서식처럼 SUM 수식으로 들어갑니다.
- 서식에는 대면·서면만 있어서 영상회의는 대면으로 집계합니다.
- 외부 라이브러리 없이 브라우저에서 직접 만들기 때문에 인터넷이 막힌 내부망에서도 동작합니다.
- 3번 시트에는 위원 연락처·생년월일이 들어가므로 제출 목적 외로 보관·공유하지 않습니다.

## 데이터에 관하여

> **이 페이지의 모든 데이터는 기능 시연을 위해 만들어낸 가상 데이터입니다.**
> 위원회·위원·회의·예산·점검 결과는 실제 경기도 위원회와 무관하며,
> 위원명은 전부 `김○○` 형태로 가명 처리했습니다.
> 소속 국·과는 `경기도 / 경제산업국 / 일자리정책과`처럼 일반 명칭을 씁니다.

편집한 내용은 브라우저에만 저장되고 저장소에는 올라가지 않습니다.

## 남은 과제

화면은 총괄·개별 담당자로 나뉘었지만 데이터는 아직 한 브라우저에 모두 들어 있습니다.
서버에서 로그인과 담당 위원회별 권한을 적용해야 실제로 자기 위원회만 볼 수 있습니다.

## 변경 내역

**2026-09 · 운영실적 서식 항목 반영**

- 위원회: 상임위, 위원회 종류, 설치근거(법령·조례), 설치구분(강행/임의), 성격, 존속기한, 위원명단·회의록 공개 여부와 비공개 사유·근거, 청년정책 위원회 여부, 올해 예산액, 비고
- 위원: 직책, 생년월일, 직업, 도의원 여부, 도 공무원 여부, 연임 횟수
- 회의: 종료일(서면회의 기간), 회의록 비공개 사유·근거, 홈페이지 게시일
- 점검 신호 추가: 회의록기한, 겸직, 연임
- 기준일 설정 추가, 연도 고정값(2026) 제거
- 수정: 개별 위원회의 `기본정보 수정` 버튼이 `위원회 추가` 창을 열던 문제
- 운영실적 서식 엑셀 내보내기 추가 (1~6번 시트)
- 이름을 `경기도 위원회 관리`로 바꾸고 데모 위원회명을 `경기도 ○○위원회`로 변경
- 컬러 세트 8종 적용 (총괄은 진하게, 개별 위원회는 연하게 한 쌍으로 바뀜)
- 설치근거 조문 바로가기(law.go.kr), 근거 조문 내용 메모
- 회의록: 발언자 칸 삭제, 누리집 게시 문구 만들기, 게시일·게시글 주소 기록, 게시 기한 D-day
- 집행내역: 연도 선택, 예산과목·과목별 예산액 입력, 과목별 집행률
- 작은 글자(원래 13.5px 이하) 1px씩 확대
- 시작 화면에 데모 둘러보기만 표시 (`DEMO_ONLY`)
- 총괄 메뉴에서 청년·예산 제거, 점검센터 → 점검기준, 요약 카드 아이콘을 이모지로
- 모든 목록에 화면 그대로 CSV 내보내기
- 회의록 버튼 제거: 회의 수정 창에서 입력, 목록에는 누리집 바로가기 버튼
- 시작 화면에서 총괄 담당자 / 개별 위원회 담당자 선택 (개별 담당자는 자기 위원회만 표시)
- 예전 버전 데이터는 불러올 때 새 칸만 빈 값으로 추가하고 기존 값은 그대로 둡니다
