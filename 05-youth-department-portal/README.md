# 부서 업무포털

사업현황·위원회·시설·자치법규를 한 화면에서 보는 도구입니다.
어느 부서든 쓸 수 있도록 **빈 상태로 시작**할 수 있습니다.

## 시작하는 세 가지 방법

페이지를 처음 열면 진입 화면이 뜹니다.

| 선택 | 무엇을 하나 |
|---|---|
| **이어서 작업하기** | 전에 작업하던 내용을 그대로 이어서 봅니다 (빈 상태·불러오기로 작업한 적이 있을 때만 보입니다) |
| **데모 둘러보기** | 가상 데이터가 채워진 상태로 기능을 살펴봅니다 |
| **빈 상태로 시작** | 부서명·팀 이름만 넣고 아무것도 없는 상태에서 직접 채웁니다 |
| **저장한 파일 불러오기** | 전에 내보낸 JSON을 열어 이어서 작업합니다 |

**페이지를 열 때마다 이 화면이 먼저 나옵니다.** 여러 사람이 둘러보는 공개 페이지라 그렇게 두었습니다.
작업하던 내용은 지워지지 않고 `이어서 작업하기`로 돌아갈 수 있습니다.

### 빈 상태에서

- 위원회·시설·자치법규 — 상단 `✎ 편집`을 켜고 `+ 추가`로 하나씩 넣습니다
- 사업현황 — 아직 한 건씩 넣는 입력 화면이 없습니다. JSON 불러오기로 채웁니다

입력한 내용은 **이 브라우저에만** 저장됩니다. 서버로 전송되지 않습니다.
다른 PC에서 이어 하거나 보관하려면 `JSON 내보내기`로 파일을 받아두세요.

## 화면 구성

상단 메뉴는 `통합 홈 / 사업현황 ▾ / 위원회 / 시설 / 조례 / 참고자료` 입니다.

- **사업현황 ▾** 를 누르면 세부메뉴(홈·사업 총괄·육성기금·검증)가 펼쳐집니다
- **참고자료** 는 조례 옆 별도 메뉴로 분리했습니다
- 사업현황 화면에서는 대시보드가 화면에 꽉 차도록 맞춰져 스크롤이 하나만 생깁니다

## 데모에 들어 있는 것

| 영역 | 분량 | 볼 수 있는 기능 |
|---|---|---|
| 사업현황 | 32개 사업 · 155행 (2021~2026) | 연도별 비교, 담당팀·사업구분·재원별 필터, 대상 시군 필터, 증감 추적, 태그, CSV 내보내기 |
| 위원회 | 6개 | 위원 명단, 개최실적, 예산·집행, 상세 서랍 |
| 시설 | 10개 | 규모·인원·예산·주요사업 상세 |
| 자치법규 | 24건 | 검색 및 law.go.kr 연결 |

편집 모드로 내용을 고칠 수 있고, JSON 내보내기/불러오기와 CSV 내보내기가 동작합니다.
편집 내용은 브라우저에만 저장되며, 오른쪽 아래 **데모 초기화** 버튼으로 처음 상태로 되돌릴 수 있습니다.

## 데이터에 관하여

> **이 페이지의 모든 데이터는 기능 시연을 위해 만들어낸 가상 데이터입니다.**
> 위원회·시설·사업·예산·성과 수치는 실재하는 기관이나 사업과 무관하며,
> 사람 이름은 전부 `김○○` 형태로 가명 처리했습니다.
> 부서명은 `OO과`, 시설 주소는 `OO시 OO구`로 익명화했고, 홈페이지 링크는 `example.com`을 씁니다.

실제 업무에 쓸 때는 편집 모드나 JSON 불러오기로 각자의 데이터를 넣어 사용합니다.
그렇게 넣은 데이터는 브라우저 안에만 남고 저장소에는 올라가지 않습니다.

## 구조

단일 HTML 파일입니다. 사업현황 대시보드는 같은 파일 안에 `iframe srcdoc`으로 들어 있어
별도 파일 없이 혼자서 동작합니다.
