# 시군 취합도구 (서식 취합 매크로)

시군별로 제출된 같은 서식의 엑셀 파일을 한 장으로 모으는 Excel 매크로 도구입니다.

## 동작 방식

배포했던 **빈 서식**을 기준으로 삼고, 제출 파일에서 같은 시군 행을 찾아 값을 옮겨 담습니다.
셀 위치가 아니라 **시군명으로 짝을 맞추기 때문에**, 제출자가 다른 시군 행을 지우거나
위아래를 잘라내도 제자리에 들어갑니다.

- 빈 서식에서 `~시 / ~군 / ~구`로 끝나는 값이 가장 많은 열을 시군명 열로 자동 인식
- 값이 겹치면 먼저 읽은 값을 남기고, 완료 메시지에 충돌 위치를 알려줌
- 빈 서식에 원래 값이 있던 칸(제목, 합계 수식 등)은 제출본이 바꿔도 가져오지 않음
- 결과는 제출 파일 폴더에 `취합결과_날짜시간.xlsx`로 저장

## 사용 순서

1. `[취합하기]` 버튼을 누릅니다.
2. 첫 번째 창에서 시군에 배포했던 **빈 서식** 파일을 고릅니다.
3. 두 번째 창에서 제출 파일들이 모여 있는 **폴더**를 고릅니다.
4. 완료 메시지가 뜨면 그 폴더에 결과 파일이 생깁니다.

## 처음 열었을 때 — 설정 두 가지

받자마자 바로 동작하지 않습니다. 아래 두 가지를 먼저 해주세요.

**(1) 매크로 차단 해제**

- 노란 띠에 '콘텐츠 사용'이 보이면 누릅니다.
- '매크로가 차단되었습니다'가 뜨면: 파일 우클릭 → 속성 → 아래쪽 **차단 해제** 체크 → 확인 후 다시 열기

**(2) 중복 모듈 정리**

현재 파일에는 같은 매크로가 `Module1`과 `취합모듈` 두 곳에 들어 있어,
그대로 실행하면 `Ambiguous name detected: 취합하기` 오류가 납니다.

- `Alt` + `F11` → 왼쪽 목록에서 `Module1` 우클릭 → **제거** → 내보내기 묻는 창에서 '아니요'
- `취합모듈` 하나만 남기면 됩니다.

**(3) 버튼 배치**

시트의 `▶ 여기에 [취합하기] 버튼을 만드세요` 자리에 버튼을 놓습니다.

- 개발 도구 탭 → 삽입 → 양식 컨트롤 **단추** → 시트에 그리기
- 매크로 선택 창에서 `취합하기` 선택 → 확인
- 버튼 이름을 '취합하기'로 바꿉니다

버튼 없이도 `Alt` + `F8` → `취합하기` → 실행으로 동작합니다.

## 주의

- 제출 파일은 빈 서식과 **칸 위치가 같아야** 합니다. 행이나 열을 끼워 넣거나 지운 파일은 엉뚱한 자리에 들어갈 수 있습니다.
- 시군명 열을 찾지 못하면(해당 형태의 값이 2개 미만) 실행되지 않습니다.
- 결과 파일은 값만 담깁니다. 원본 서식의 수식은 빈 서식 쪽 것이 그대로 유지됩니다.

## 필요 환경

- Windows + Microsoft Excel (매크로 실행 가능 환경)
- `Scripting.Dictionary`, `Application.FileDialog` 사용 — Windows용 Excel 전용입니다. Mac에서는 동작하지 않습니다.
