한글문서 PDF 변환 프로그램

여러 HWP/HWPX 문서를 PDF로 한 번에 변환하는 Windows 일괄 변환 프로그램입니다.

Windows EXEC# WinFormsBatch PDF
프로그램 ZIP 다운로드EXE 바로 받기

주요 기능

  • HWP/HWPX 파일·폴더 드래그앤드롭
  • 하위 폴더 포함 및 중복 파일 자동 제거
  • 원본 파일명 그대로 PDF 저장
  • 원본 폴더 또는 별도 저장 폴더 선택
  • 기존 PDF 자동 이름변경·건너뛰기·덮어쓰기
  • 진행률, 파일별 성공·실패 로그, 작업 취소

사용 환경

Windows와 데스크톱 한컴오피스 한글이 필요하며, HWPFrame.HwpObject 자동화가 가능한 환경에서 동작합니다.

한컴 보안모듈 DLL 자체는 프로그램에 포함되어 있지 않습니다. 조직 내 배포 전 한컴 자동화 이용 조건과 사내 보안정책을 확인하세요.

공동 개발

C# WinForms 소스와 x86/x64 빌드 파일을 함께 제공합니다.
