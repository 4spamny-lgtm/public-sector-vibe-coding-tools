한글문서 병합 프로그램

여러 HWP/HWPX 문서를 원하는 순서대로 하나의 문서로 취합하는 Windows 프로그램입니다.

Windows EXEC# WinForms한컴오피스 필요
프로그램 ZIP 다운로드EXE 바로 받기

주요 기능

  • HWP/HWPX 파일·폴더 드래그앤드롭
  • 여러 폴더의 문서 함께 추가 및 중복 제거
  • 목록 순서 또는 파일명 자연정렬
  • ▲/▼ 버튼으로 취합 순서 조정
  • 파일별 성공·실패 로그 및 오류 파일 건너뛰기
  • 결과 HWPX 저장 폴더 지정

사용 환경

Windows와 데스크톱 한컴오피스 한글이 필요하며, HWPFrame.HwpObject 자동화가 가능한 환경에서 동작합니다.

서명되지 않은 EXE는 Windows SmartScreen 경고가 나타날 수 있습니다. 조직 내 배포 전에는 코드서명과 사내 보안정책을 확인하세요.

공동 개발

실행파일뿐 아니라 C# 원본과 빌드 파일도 저장소에 포함했습니다.
